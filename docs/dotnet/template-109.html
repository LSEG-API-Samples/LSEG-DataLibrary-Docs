Open

Allows you to open the Pricing connection by sending corresponding requests for all requested instruments. It will be opened once all the requested instruments are received either a Refresh or a Status event. Then the Pricing.Stream can be used in order to retrieve data.

Syntax

Stream.State Open(CancellationToken cancellationToken = default)

Returned value

A Stream.State value indicating if the stream opened.

Usage

The following example demonstrates how to create and open a pricing stream.

var stream = Pricing.Definition("EUR=").GetStream();

var streamState = stream.Open();
