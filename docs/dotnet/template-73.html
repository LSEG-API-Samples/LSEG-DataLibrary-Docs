IPA.VolatilitySurface.Definition object

Definition allows you to retrieve Volatility Surface data within a specific session.

Syntax

VolatilitySurface.Definition(JObject request = null)

VolatilitySurface Definition Parameters

Value Description Optional Default value
request A request object required to price a Volatility Surface. Yes null

VolatilitySurfaceDefinition Methods

IVolatilitySurfaceDefinition NativeRequestParams(JObject request)
The native JSON request. The request object is a flexible interface supporting all IPA Financial Contract interfaces. Optional.

IVolatilitySurfaceDefinition Closure(object closure)
Optionally, include a user-defined Closure to match specific requests and responses.

IFinancialContractsDefinitionParams Properties { get; }
Gets the properties describing the values within the defined request (NativeRequestParams, Closure).

Asynchronously retrieve the data from the backend service.

Returned value

IVolatilitySurfaceDefinition object.

When requesting data using the GetData/GetDataAsync methods, we receive an IDataSetResponse object (implements IResponse). The response object contains a "Data" property of IDataSet type (Raw, Table, Records, Errors, IsEmpty - see FinancialContracts.Definition).

Usage

The following example demonstrates how to request an ETI and an FX Volatility Surface using native request objects:

using LSEG.Data.Content.IPA;
using Newtonsoft.Json.Linq;

var etiSurface = new JObject()
{
    ["surfaceTag"] = "myEti",
    ["underlyingType"] = "Eti",
    ["underlyingDefinition"] = new JObject()
    {
        ["instrumentCode"] = "BNPP.PA"
    },
    ["surfaceParameters"] = new JObject()
    {
        ["priceSide"] = "Mid",
        ["volatilityModel"] = "SSVI",
        ["xAxis"] = "Date",
        ["yAxis"] = "Moneyness"
    },
    ["surfaceLayout"] = new JObject()
    {
        ["format"] = "Matrix",
        ["yPointCount"] = 10
    }
};

var fxSurface = new JObject()
{
    ["surfaceTag"] = "myFx",
    ["underlyingType"] = "Fx",
    ["underlyingDefinition"] = new JObject()
    {
        ["fxCrossCode"] = "EURUSD"
    },
    ["surfaceParameters"] = new JObject()
    {
        ["calculationDate"] = "2018-08-20T00:00:00Z",
        ["returnAtm"] = true,
        ["xAxis"] = "Date",
        ["yAxis"] = "Strike"
    },
    ["surfaceLayout"] = new JObject()
    {
        ["format"] = "Matrix"
    }
};

var requestDetails = new JObject()
{
    ["universe"] = new JArray(etiSurface, fxSurface)
};

var response = VolatilitySurface.Definition(requestDetails).GetData();
