ESG.Universe object

Universe provides access to the full universe of organizations, with relevant identifiers, that currently have ESG coverage.

Syntax

Universe.Definition()

Asynchronously retrieve the data from the backend service.

Returned value

IUniverseDefinition object.

When requesting data using the GetData/GetDataAsync methods, we receive an IDataSetResponse object (implements IResponse). The response object contains a "Data" property of IDataSet type.
