About Summaries.Stream object

Summaries.Stream objects are used to retrieve, process and manage real-time historical pricing summaries (Interday and Intraday bars), blending live updates into the historical summaries retrieved via Summaries.Definition.

Properties

Stream.State OpenState { get; }
Current state of the stream.

Name Description
State.Pending The stream is waiting to be opened or is closed.
State.Opened The stream is open and ready to work.
State.Closed The stream is closed.

ISession Session { get; }
Session used to open the stream.

int LastMsgSeqNum { get; }
The sequence number (SeqNumber) for the last real-time message processed. This value can be used to cross-reference the generated INSERT or UPDATE record received.

JObject InstrumentMetadata { get; }
The instrument metadata for the given stream instrument.

Summaries.Interval Interval { get; }
The specified interval for the timeseries bars.

ISummariesDefinitionParams Definition { get; }
Retrieve the parameters defined for the streaming request (see Summaries.Definition Properties).

Summaries Stream Interface methods

Stream.State Open(CancellationToken cancellationToken = default)
Open the stream synchronously. Request the data from the platform and wait until all initial responses have arrived.

Task<Stream.State> OpenAsync(CancellationToken cancellationToken = default)
Open the stream asynchronously.

void Close()
Task CloseAsync()
Close all opened resources.

ISummariesStream OnInsert(Action<IDataSet, ISummariesStream> cb)
Callback invoked upon receiving historical data bars to be inserted at specific points in time.

ISummariesStream OnUpdate(Action<IDataSet, ISummariesStream> cb)
Callback invoked upon receiving an update to the most recent historical bar.

ISummariesStream OnStatus(Action<JObject, ISummariesStream> cb)
Callback invoked when a stream status event occurs on the service.

ISummariesStream OnError(Action<string, ISummariesStream> cb)
Callback invoked if an error occurs resulting from the request. Required.

ISummariesStream BlendRealtimeInSnapshot(bool blendRealtimeInSnapshot)
Enables or disables the blending of real-time updates with the historical data for the initial snapshot retrieval. Optional. Default: false.

ISummariesStream Streaming(bool streaming)
Specify whether the stream will deliver the initial image followed by updates. A value of false implies no streaming and that only the initial image will be delivered (a snapshot). Optional. Default: true.

Usage

The following example demonstrates how to retrieve streaming daily summaries for AAPL.O, blending real-time updates into the initial historical snapshot.

using LSEG.Data.Content.HistoricalPricing;

var stream = Summaries.Definition("AAPL.O")
                      .Fields("HIGH_1", "LOW_1", "OPEN_PRC", "TRDPRC_1", "HST_CLOSE", "NUM_MOVES", "ACVOL_UNS")
                      .Interval(Summaries.Interval.P1D)
                      .Count(5)
                      .GetStream();

stream.OnInsert((data, s) => Console.WriteLine($"INSERT: {DateTime.Now}. RT Seqnum: {s.LastMsgSeqNum}\n{data.Table}"))
      .OnUpdate((update, s) => Console.WriteLine($"UPDATE: {DateTime.Now}. RT Seqnum: {s.LastMsgSeqNum}\n{update.Table}"))
      .OnStatus((status, s) => Console.WriteLine($"Received status: {status}"))
      .OnError((error, s) => Console.WriteLine($"Received error: {error}"))
      .BlendRealtimeInSnapshot(true)
      .Open();
