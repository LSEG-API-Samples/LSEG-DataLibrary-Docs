About ESG

ESG (Environmental Social Governance) content objects give your application access to LSEG's ESG data, delivered at the Company Level, using multiple content objects belonging to the ESG group:

  • Basic - An overview of 6 common data items from the latest Financials, for the current year only.
  • Scores - LSEG's proprietary ESG Scores with full available history.
  • Measures - Full coverage of over 400 ESG data items, including LSEG's proprietary ESG Scores, with full available history.
  • DirScores - Diversity Inclusion Ratings Scores.
  • Universe - The full universe of organizations, with relevant identifiers, that currently have ESG coverage.

The user can use the following identifier types when specifying a universe - there is no need to define what identifier type is being used: Organization PermID, Instrument PermID, Quote PermID, RIC Code, ISIN, CUSIP, SEDOL, Valoren, Wert.
