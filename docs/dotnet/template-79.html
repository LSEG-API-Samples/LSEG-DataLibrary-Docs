Machine Readable News (MRN) Definition

Using this definition, we can retrieve real-time news headlines, stories, news analytics about companies and their assets and macroeconomic events. Machine Readable News data is retrieved using streams. The streams can be setup with callbacks for different events like incoming data (stream inserts or updates), the stream status and in case any errors are encountered. 

    var definition = MachineReadableNews.Definition();

    // Set the datafeed then retrieve a streaming object.
    using (var stream = definition.NewsDatafeed(feed).GetStream())
    {
        // A token can be provided to end the ongoing task after a certain period
        var tokenSource = new CancellationTokenSource(TimeSpan.FromSeconds(10));
        
        // Define our real-time processing then open the stream...
        stream
            .OnError((err, s) => { })
            .OnStatus((status, s) => { })
            .OnNewsStory((newsItem, s) => { })
            .OnNewsAnalyticsAssets((newsItem, s) => { })
            .OnNewsAnalyticsEvents((newsItem, s) => { })
            .Open(tokenSource.Token);

        Console.ReadLine();
    }

Syntax

MachineReadableNews.Definition()

MRNDefinition Methods

IMRNDefinition NewsDatafeed(MachineReadableNews.Datafeed dataFeed)
IMRNDefinition NewsDatafeed(string dataFeed)
The MRN data feed to subscribe to (MRN_STORY, MRN_NA_ENT0, MRN_NA_DOC). Optional. Default: MRN_STORY - headlines and news stories.

IMRNDefinition Service(string service)
Override the default service used to manage the real-time streaming data. Optional. Default: defined within the streaming platform.

IMRNDefinition ExtendedParams(JObject extendedParams)
Define additional request properties, formed as defined within the WebSocket Request specifications, that will be merged with all other properties specified. Optional.

IMRNDefinitionParams Properties { get; }
Gets the properties describing the values within the defined request (Service, DataFeed, ExtendedParams).

Retrieving data

IMRNStream GetStream()
IMRNStream GetStream(ISession session)
Retrieve a streaming interface to manage real-time updates for the specified data feed.

MRNStream Interface methods

IMRNStream OnNewsStory(Action<IMRNStoryData, IMRNStream> newsCb)
Callback invoked when a complete news story has been received from the MRN service. Required.

IMRNStream OnNewsAnalyticsAssets(Action<IMRNAnalyticsData, IMRNStream> newsCb)
Callback invoked when a complete News Analytics: Company and C&E assets item has been received from the MRN service. Required.

IMRNStream OnNewsAnalyticsEvents(Action<IMRNAnalyticsData, IMRNStream> newsCb)
Callback invoked when a complete News Analytics: Macroeconomic News & Events item has been received from the MRN service. Required.

IMRNStream OnNewsGenericEvents(Action<JObject, IMRNStream> newsCb)
Reserved for unknown datafeeds. Required.

IMRNStream OnStatus(Action<JObject, IMRNStream> statusCb)
Callback invoked when an EventCode event occurs on the MRN streaming service. Required.

IMRNStream OnError(Action<JObject, IMRNStream> errorCb)
Callback invoked if an error occurs resulting from the request. Required.

IMRNDefinitionParams Definition { get; }
Retrieve the parameters defined for the streaming request (see MRNDefinition Properties above).

Returned value

IMRNDefinition object.

IMRNStoryData - properties

IMRNStoryData extends INewsItem (delivered via OnNewsStory):

string NewsStory { get; }
NewsStoryType MsgType { get; }
NewsUrgencyType Urgency { get; }
string HeadlineTitle { get; }
IList<string> Sources { get; }
IList<string> Languages { get; }
IList<string> Subjects { get; }
IList<string> RICCodes { get; }
DateTime CreationDate { get; }
DateTime UpdateDate { get; }
JObject Raw { get; }

NewsStoryType values: Unknown, Alert, FirstTake, SubsequentTake, Correction, Corrected, Update, Deletion.

IMRNAnalyticsData - properties

IMRNAnalyticsData extends INewsItem (delivered via OnNewsAnalyticsAssets/OnNewsAnalyticsEvents):

IList<INewsAssetScores> Scores { get; }
NewsUrgencyType Urgency { get; }
string HeadlineTitle { get; }
IList<string> Sources { get; }
IList<string> Languages { get; }
IList<string> Subjects { get; }
IList<string> RICCodes { get; }
DateTime CreationDate { get; }
DateTime UpdateDate { get; }
JObject Raw { get; }

Each entry in Scores is an INewsAssetScores:

string AssetClass { get; }
string AssetName { get; }
double? Relevance { get; }
double? SentimentNegative { get; }
double? SentimentNeutral { get; }
double? SentimentPositive { get; }
