Headlines

Headlines news data can be retrieved as a list of headlines using the Headlines definition.

Each headline contains a raw content field, a story ID, a headline title and several metadata fields.

These metadata fields contain information about the creators, sources, languages, subjects and instrument codes.

Syntax

Headlines.Definition()

HeadlinesDefinition Methods

IHeadlinesDefinition Query(string query)
A news query expression. Optional. Default: all headlines.

IHeadlinesDefinition Count(uint count)
The number of headlines. Optional. Default: 100. A value of 0 (zero) retrieves all available headlines within the query - typically only used when the query specifies a date range.

IHeadlinesDefinition Sort(Headlines.SortOrder sort)
The sort order of the headlines (newToOld, oldToNew). Optional. Default: newToOld.

IHeadlinesDefinition Closure(object closure)
Optionally, include a user-defined Closure to match specific requests and responses.

IHeadlinesDefinitionParams Properties { get; }
Gets the properties describing the values within the defined request (Query, Count, Sort, PageSize, Closure).

Asynchronously retrieve the data from the backend service.

Returned value

IHeadlinesDefinition object.

When requesting data using the GetData/GetDataAsync methods, we receive an IHeadlinesResponse object (implements IResponse). The response object contains a "Data" property of IHeadlinesData type.

IHeadlinesData - properties

IList<IHeadlineData> Headlines { get; }
JToken Raw { get; }

Each entry in Headlines is an IHeadlineData (extends INewsItem):

IHeadlineData - properties

string StoryId { get; }
IList<string> Creators { get; }
NewsUrgencyType Urgency { get; }
string HeadlineTitle { get; }
IList<string> Sources { get; }
IList<string> Languages { get; }
IList<string> Subjects { get; }
IList<string> RICCodes { get; }
DateTime CreationDate { get; }
DateTime UpdateDate { get; }
JObject Raw { get; }

NewsUrgencyType values: Regular, Hot.

Usage

The code snipet bellow, exemplifies a couple of use cases for retrieving headlines data. 


    var definition = Headlines.Definition();

    // Default Count: Retrieve the most recent 100 headlines about any instrument
    var response1 = definition.GetData();

    // Default Count: Retrieve most recent 100 headlines for Apple
    var response2 = Headlines.Definition().Query("R:AAPL.O").GetData();

    // Specify Count: Retrieve most recent N headlines for Apple
    var response3 = Headlines.Definition().Query("R:AAPL.O").Count(15).GetData();
    
    // Retrieve a large number of headlines and a callback to retrieve each page.  Each page contains 100 headlines.
    Headlines.Definition()
              .Query("R:AAPL.O")
              .Count(350)
              .GetData((response, def, s) =>
              {
                  // Use the response object and display the desired headlines details
              });

    // Retrieve headlines using queries and sort the result.
    var startdate = DateTime.Now.AddMonths(-15);
    var enddate = startdate.AddDays(1);

    var query = $"Apple daterange:\"{startdate:yyyy-MM-dd},{enddate:yyyy-MM-dd}\"";
    
    var response = Headlines.Definition()
                            .Query(query)
                            .Count(0)
                            .Sort(Headlines.SortOrder.oldToNew)
                            .GetData();

Headline entries can be sorted using the Sort() and providing a Headlines.ShortOrder value.
The available values are "oldToNew" and "newToOld".
