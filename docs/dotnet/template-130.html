RDP Web Socket

Overview

The RDPWebSocket interface carries the required properties defining a WebSocket interface used by the OMM-based Streaming interfaces defined within RDP.

RDPWebSocket members

RDPWebSocket (LSEG.Data.Delivery.Stream.RDPWebSocket) is a static class exposing the current WebSocket registration:

IsWebSocketRegistered (static property, bool)
Whether a WebSocket implementation has been registered.

Register (static property, RDPRegisterWebSocket)
Register a specific WebSocket implementation. See below.

RDPRegisterWebSocket members

RegisterWebSocketImpl (property, Func<IWebSocket>)
Register a custom-developed IWebSocket implementation.

The ClientWebSocket(), NinjaWebSockets(), WebSocket4Net(), WebSocketClient(), and WebSocketSharp() calls used below are extension methods, each shipped in a separate optional NuGet package (e.g. LSEG.Data.WebSockets.NinjaWebSockets, LSEG.Data.WebSockets.WebSocket4Net) rather than the core LSEG.Data package. Add a reference to the corresponding package to use a given implementation.

IWebSocket members

IWebSocket is the interface implemented by every registered WebSocket implementation (built-in or custom, via RegisterWebSocketImpl).

ConnectAsync(CancellationToken cancellationToken)
Issue a connection request into the server.

SendAsync(string msg)
Send the specified message to the WebSocket server.

CloseAsync()
Issue a close request into the server.

Register(IWebSocketDefinitionParams wsParams)
Register the connection details and the callback events used to capture connection and message events generated by the server.

State (property, RDPWebSocket.State)
State of the WebSocket client.

IWebSocketDefinitionParams members

Details used to interact with RDP streaming interfaces, supplied to IWebSocket.Register(...).

Url (property, string)
Connection channel URL for the WebSocket server.

Protocol (property, string)
WebSocket protocol setting required by the server.

SecureConnection (property, bool)
Whether the underlying WebSocket requires a secure connection.

OpenCb (property, Action<IWebSocket>)
Callback invoked when the WebSocket channel successfully connects.

MessageCb (property, Action<IWebSocket, string>)
Callback invoked when a new message arrives on the WebSocket channel.

CloseCb (property, Action<IWebSocket, string>)
Callback invoked when the WebSocket channel closes.

ErrorCb (property, Action<IWebSocket, string>)
Callback invoked when an error occurs on the WebSocket channel.

Usage

We can use this interface to register a specific socket other than the one specified in configuration. 

    RDPWebSocket.Register.ClientWebSocket(); // Library default

    RDPWebSocket.Register.NinjaWebSockets();

    RDPWebSocket.Register.WebSocket4Net(); // WebSocket4Net (originated from SuperWebSocket)

    RDPWebSocket.Register.WebSocketClient();

    RDPWebSocket.Register.WebSocketSharp();
