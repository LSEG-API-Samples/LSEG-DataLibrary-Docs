DesktopSession

The DesktopSession connects to the platform through LSEG Eikon or LSEG Workspace running on the same machine as your application. Each application connecting to the desktop must include an application key. The desktop provides a means to retrieve content from the LSEG Data Platform.

This session type does not work with Eikon Web or Workspace for Web. For a connection that does not host the full desktop application, see DesktopDirectSession; to connect directly to the platform, see PlatformSession.

The types on this page live in the LSEG.Data.Core namespace.

Entry points

The DesktopSession class exposes a Definition(...) factory that returns an IDesktopSessionDefinition fluent builder; the builder's GetSession() method finalises the request and returns an ISession.

DesktopSession.Definition(string sessionName = default)
DesktopSession.Definition(Stream stream, string resourceName = default)
DesktopSession.Definition(JObject config)
DesktopSession.Definition(string sessionName, Stream stream, string resourceName = default)
DesktopSession.Definition(string sessionName, JObject config)
Define a Desktop Session request. When sessionName is omitted, the sessions.desktop.default entry from the configuration is used.

IDesktopSessionDefinition members

IDesktopSessionDefinition is the fluent builder returned by Definition(...). Each setter returns the builder for chaining; GetSession() (inherited from ISessionDefinition) produces the ISession.

Member Kind Description
IDesktopSessionDefinition AppKey(string appKey) method Desktop Application key necessary to authenticate the specific application with the session. Required.
IDesktopSessionDefinition AppName(string appName) method Application name defined by the user and used for request-tracking purposes. Required.
IDesktopSessionDefinition Port(IEnumerable<string> ports) method Optional Desktop Proxy ports. Default: value extracted from .portInUse.
IDesktopSessionDefinition Port(params int[] ports) method Optional Desktop Proxy ports. Default: value extracted from .portInUse.

IDesktopSessionDefinitionParams members

IDesktopSessionDefinitionParams exposes the read-only view of the parameters defined for the session (retrieved via IDesktopSession.Definition).

Member Kind Description
string AppKey property Desktop Application key necessary to authenticate the specific application with the session.
string AppName property Application name defined by the user in the case of human-friendly request tracking.
int[] Ports property Specified Desktop Proxy ports via interface or configuration. If no value is defined upon definition, the value is set when the session is opened.

IDesktopSession members

IDesktopSession is the desktop-specific session interface. It extends the common ISession interface (see Sessions for Open, OpenAsync, Close, OnState, OnEvent, and the state/event members) with the following:

Member Kind Description
IDesktopSession OnStreamingEndpoint(Action<string, IList<IStreamingEndpoint>, ISession> cb) method Optional callback invoked to report all the desktop streaming endpoints.
IDesktopSessionDefinitionParams Definition property Retrieve the parameters defined for the Desktop Session.

Example

Create a Desktop session in code:

using LSEG.Data.Core;

using (ISession session = DesktopSession.Definition()
                                        .AppKey("<your-app-key>")
                                        .AppName("MyApp")
                                        .GetSession())
{
    if (session.Open() == Session.State.Opened)
    {
        // Use the session with Content or Delivery layer objects
    }
}
