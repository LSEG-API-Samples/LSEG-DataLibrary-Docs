DesktopDirectSession

The DesktopDirectSession communicates with the platform via WAG (Workspace API Gateway). It is intended for applications that need direct access to the streaming and RESTful services exposed to the desktop without hosting the Workspace application. The session provides a means to retrieve content from the LSEG Data Platform via WAG.

For a connection that hosts the full desktop application, see DesktopSession; to connect directly to the platform, see PlatformSession.

The types on this page live in the LSEG.Data.Core namespace.

Entry points

The DesktopDirectSession class exposes a Definition(...) factory that returns an IDesktopDirectSessionDefinition fluent builder; the builder's GetSession() method finalises the request and returns an ISession.

DesktopDirectSession.Definition(string sessionName = default)
DesktopDirectSession.Definition(Stream stream, string resourceName = default)
DesktopDirectSession.Definition(JObject config)
DesktopDirectSession.Definition(string sessionName, Stream stream, string resourceName = default)
DesktopDirectSession.Definition(string sessionName, JObject config)
Define a DesktopDirect Session request. When sessionName is omitted, the sessions.desktop-direct.default entry from the configuration is used.

IDesktopDirectSessionDefinition members

IDesktopDirectSessionDefinition is the fluent builder returned by Definition(...). Each setter returns the builder for chaining; GetSession() (inherited from ISessionDefinition) produces the ISession.

Member Kind Description
IDesktopDirectSessionDefinition AppName(string appName) method Application name defined by the user and used for request-tracking purposes. Required.
IDesktopDirectSessionDefinition DacsApplicationID(string applicationId) method The ID of the application connecting in. Optional. Default: 256.
IDesktopDirectSessionDefinition DacsPosition(string position) method The IP-address position of the application logging in. Optional. Default: local IP address.
IDesktopDirectSessionDefinition DacsUserName(string username) method The DACS user name. Optional. Default: based on the machine login ID.
IDesktopDirectSessionDefinition Host(string host) method IP address or hostname and port of the Advanced Distribution Server (ADS) streaming real-time content. When defined, all streaming communication goes through this interface by default. Format: <IP>|<hostname>:<port>, e.g. elektron:15000.
IDesktopDirectSessionDefinition TakeRealTimeControl(bool takeRealTimeControl) method Defines whether a newly opened session will "steal" the real-time access to streaming data when the user already has an opened session. Optional. Default: true. Set to false to open a session that does not take over real-time access and user wants only to query the APIs without streaming capabilities.
IDesktopDirectSessionDefinition WithAuthenticationProvider(IAuthenticationProvider provider) method Sets the authentication provider. Required — a DesktopDirect session cannot open without one. Currently only DesktopDirect supports authentication using Entra as IDP and Heimdall as an internal auth service; use the EntraProvider implementation described below.

WithAuthenticationProvider and TakeRealTimeControl are the two settings that most directly affect how a DesktopDirect session behaves: the former is mandatory for the session to authenticate at all, and the latter decides whether opening this session takes real-time streaming access away from any other session already using the same identity.

Authentication — EntraProvider

The only concrete IAuthenticationProvider implementation shipped by the library is EntraProvider (LSEG.Data.Authentication.IdentityProviders.EntraProvider). It authenticates using Entra as the identity provider and Heimdall as the internal auth service.

Member Kind Description
EntraProvider(Func<Task<string>> idpTokenProvider) constructor Builds the provider from a callback that asynchronously returns an Entra ID token (for example, one backed by MSAL). Required; throws ArgumentNullException if idpTokenProvider is null.
EntraProvider(ITokenProvider tokenProvider) constructor Builds the provider from an ITokenProvider implementation instead of a raw callback. Required; throws ArgumentNullException if tokenProvider is null.

ITokenProvider (LSEG.Data.Authentication.IdentityProviders.ITokenProvider) is the contract users can implement to supply their own token-minting mechanism. It exposes a single member: Task<string> GetAccessTokenAsync(), which asynchronously returns the access token.

IDesktopDirectSession members

IDesktopDirectSession is the DesktopDirect-specific session interface. It extends the common ISession interface (see Sessions for Open, OpenAsync, Close, OnState, OnEvent, and the state/event members) with the following:

Member Kind Description
IDesktopDirectSession OnStreamingEndpoint(Action<string, IList<IStreamingEndpoint>, ISession> cb) method Optional callback invoked to report all the DesktopDirect streaming endpoints.
IDesktopDirectSessionDefinitionParams Definition property Retrieve the parameters defined for the DesktopDirect Session.

Example

Create a DesktopDirect session authenticated with EntraProvider, controlling real-time access with TakeRealTimeControl:

using LSEG.Data.Authentication.IdentityProviders;
using LSEG.Data.Core;

// Wrap your Entra/MSAL token acquisition in an async callback.
static async Task<string> GetAccessToken() => await new MsalClient().GetIDPToken("<your-entra-client-id>");

// takeRealTimeControl: true -> this session will get real-time data,
// "stealing" it from any other session already using the same identity.
using (ISession session = DesktopDirectSession.Definition()
                                              .WithAuthenticationProvider(new EntraProvider(GetAccessToken))
                                              .TakeRealTimeControl(true)
                                              .GetSession())
{
    session.OnState((state, msg, s) => Console.WriteLine($"State: {state} - {msg}"))
           .OnEvent((eventCode, msg, s) => Console.WriteLine($"Event: {eventCode} - {msg}"));

    if (session.Open() == Session.State.Opened)
    {
        // Use the session with Content or Delivery layer objects
    }
}
