Top News Headlines

Once you have retrieved a Top News page ID (see Top News), you can use it to retrieve the headlines for that page.

var page = TopNews.Definition().GetData().Data.Categories["MARKETS"][0];

var headlines = TopNewsHeadlines.Definition(page.TopNewsID).GetData();

Syntax

TopNewsHeadlines.Definition()
TopNewsHeadlines.Definition(string newsID)

TopNewsHeadlinesDefinition Methods

ITopNewsHeadlinesDefinition NewsId(string newsId)
Specify the ID of the Top News page. The ID is available when you retrieve the Top News Categories (ITopNewsPage.TopNewsID). Required.

ITopNewsHeadlinesDefinition Closure(object closure)
Optionally, include a user-defined Closure to match specific requests and responses.

ITopNewsHeadlinesDefinitionParams Properties { get; }
Gets the properties describing the values within the defined request (NewsId, Closure).

Returned value

ITopNewsHeadlinesDefinition object.

When requesting data using the GetData/GetDataAsync methods, we receive an ITopNewsHeadlinesResponse object (implements IResponse). The response object contains a "Data" property of ITopNewsHeadlinesData type.

ITopNewsHeadlinesData - properties

IList<ITopNewsHeadlinesNode> Headlines { get; }
JToken Raw { get; }

Each entry in Headlines is an ITopNewsHeadlinesNode:

ITopNewsHeadlinesNode - properties

string Text { get; }
string Snippet { get; }
string ImageId { get; }
DateTime VersionCreated { get; }
string StoryId { get; }

The StoryId can be used to retrieve the full story (see News Stories). The ImageId can be used to retrieve the associated image (see Images).
