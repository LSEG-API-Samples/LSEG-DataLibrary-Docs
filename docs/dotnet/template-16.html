About Events.Stream object

Events.Stream objects are used to retrieve, process and manage real-time historical pricing events, blending live trades, quotes and corrections into the historical events retrieved via Events.Definition.

Properties

Stream.State OpenState { get; }
Current state of the stream.

Name Description
State.Pending The stream is waiting to be opened or is closed.
State.Opened The stream is open and ready to work.
State.Closed The stream is closed.

ISession Session { get; }
Session used to open the stream.

int LastMsgSeqNum { get; }
The sequence number (SeqNumber) for the last real-time message processed. This value can be used to cross-reference the generated INSERT or UPDATE record received.

JObject InstrumentMetadata { get; }
The instrument metadata for the given stream instrument.

IEventsDefinitionParams Definition { get; }
Retrieve the parameters defined for the streaming request (see Events.Definition Properties).

Events Stream Interface methods

Stream.State Open(CancellationToken cancellationToken = default)
Open the stream synchronously. Request the data from the platform and wait until all initial responses have arrived.

Task<Stream.State> OpenAsync(CancellationToken cancellationToken = default)
Open the stream asynchronously.

void Close()
Task CloseAsync()
Close all opened resources.

IEventsStream OnInsert(Action<IDataSet, IEventsStream> cb)
Callback invoked upon receiving historical data bars to be inserted at specific points in time.

IEventsStream OnUpdate(Action<IDataSet, IEventsStream> cb)
Callback invoked upon receiving an update to the most recent historical bar.

IEventsStream OnStatus(Action<JObject, IEventsStream> cb)
Callback invoked when a stream status event occurs on the service.

IEventsStream OnError(Action<string, IEventsStream> cb)
Callback invoked if an error occurs resulting from the request. Required.

Usage

The following example demonstrates how to retrieve streaming trade events for AAPL.O, blending real-time updates into the historical data.

using LSEG.Data.Content.HistoricalPricing;

var stream = Events.Definition("AAPL.O")
                   .Fields("RTL", "SEQNUM", "TRDPRC_1", "TRDVOL_1", "HIGH_1", "LOW_1", "TRADE_ID", "QUALIFIERS")
                   .EventTypes(Events.EventType.trade)
                   .Count(5)
                   .GetStream();

stream.OnInsert((data, s) => Console.WriteLine($"INSERT: {DateTime.Now}. RT Seqnum: {s.LastMsgSeqNum}\n{data.Table}"))
      .OnUpdate((update, s) => Console.WriteLine($"UPDATE: {DateTime.Now}. RT Seqnum: {s.LastMsgSeqNum}\n{update.Table}"))
      .OnStatus((status, s) => Console.WriteLine($"Received status: {status}"))
      .OnError((error, s) => Console.WriteLine($"Received error: {error}"))
      .Open();
