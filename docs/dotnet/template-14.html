Events.Definition object

This object defines the request definition used to retrieve Historical pricing events data.

Syntax

Events.Definition()
Events.Definition(params string[] items)
Events.Definition(IEnumerable<string> items)

Parameters

Value Description Optional Default value
items Single instrument, multiple instruments or list of instruments No -

You can set one or more universes when calling the Definition() method. Another way of specifying the universe is using the Universe() method in continuation of the Definition() method. For a request to be valid, at least one universe is required.

Streaming usage

The following example demonstrates how to retrieve streaming trade events for AAPL.O, blending real-time updates into the historical data.

using LSEG.Data.Content.HistoricalPricing;

var stream = Events.Definition("AAPL.O")
                   .Fields("RTL", "SEQNUM", "TRDPRC_1", "TRDVOL_1", "HIGH_1", "LOW_1", "TRADE_ID", "QUALIFIERS")
                   .EventTypes(Events.EventType.trade)
                   .Count(5)
                   .GetStream();

stream.OnInsert((data, s) => Console.WriteLine($"INSERT: {DateTime.Now}. RT Seqnum: {s.LastMsgSeqNum}\n{data.Table}"))
      .OnUpdate((update, s) => Console.WriteLine($"UPDATE: {DateTime.Now}. RT Seqnum: {s.LastMsgSeqNum}\n{update.Table}"))
      .OnStatus((status, s) => Console.WriteLine($"Received status: {status}"))
      .OnError((error, s) => Console.WriteLine($"Received error: {error}"))
      .Open();

Returned value

IEventsDefinition object.

When requesting data using the GetData/GetDataAsync methods, we receive an IDataSetResponse object (implements IResponse). The response object contains a "Data" property of IDataSet type.

IDataSet - properties

JToken Raw { get; }
DataTable Table { get; }
IList<IDataSetRecord> Records { get; }
JToken Errors { get; }
bool IsEmpty { get; }

Each entry in Records is an IDataSetRecord describing the requested Universe, the Fields returned, and the corresponding Data points for that instrument.

Usage

The following example demonstrates how to create a historical pricing events definition object for LSEG.L which retrieves the 20 most recent events.

using LSEG.Data.Content.HistoricalPricing;

var definition = Events.Definition("LSEG.L");

The following example demonstrates how to get the last 3 historical pricing data rows for VOD.L and truncate the data to retrieve only several specific fields:

var definition = Events.Definition().Universe("VOD.L")
                                    .Count(3)
                                    .Fields("DATE_TIME", "EVENT_TYPE", "BID", "ASK", "ASKSIZE");

var response = await definition.GetDataAsync();

The following example demonstrates how to get the last five historical pricing data rows for VOD.L, specifying the event type and adjustment type 

var response = Events.Definition("VOD.L")
                     .EventTypes(Events.EventType.trade)
                     .Adjustments(Events.Adjustments.exchangeCorrection)
                     .GetData();
