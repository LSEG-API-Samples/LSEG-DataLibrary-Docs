News Images

News Images can be retrieved using an image ID, typically found within News Online Reports or Top News Headlines content.

IImageResponse response = Image.Definition(imageId).GetData();

byte[] imageBytes = response.Data.Image;

Syntax

Image.Definition()
Image.Definition(string imageId)

ImageDefinition Methods

IImageDefinition ImageId(string imageId)
The ID of the image. Required.

IImageDefinition ImageType(Image.ImageType type)
Specify if we want the response to come back in an HTML format (JSON, IMAGE). Optional. Default: JSON.

IImageDefinition Rendition(string rendition)
Specifies the rendition type for the image. For Online Reports only. Available values: baseImage, filedImage, thumbnail, viewImage. Optional.

IImageDefinition Closure(object closure)
Optionally, include a user-defined Closure to match specific requests and responses.

IImageDefinition ExtendedParams(JObject extendedParams)
Apply any properties that are not available within this request interface. Optional.

IImageDefinitionParams Properties { get; }
Gets the properties describing the values within the defined request (ImageId, ImageType, Rendition, Closure, ExtendedParams).

Returned value

IImageDefinition object.

When requesting data using the GetData/GetDataAsync methods, we receive an IImageResponse object (implements IResponse). The response object contains a "Data" property of IImageData type.
