Analyze

Description

Computes a tree expression from a user query string.
Breaks down a user query string into News related entities, then aggregates them into a boolean filtering tree.

Syntax

Analyze.Definition()
Analyze.Definition(string query)

AnalyzeDefinition Methods

IAnalyzeDefinition Query(string query)
A news query expression. Optional. Default: no query conditions.

IAnalyzeDefinition Closure(object closure)
Optionally, include a user-defined Closure to match specific requests and responses.

IAnalyzeDefinition ExtendedParams(JObject extendedParams)
Apply any properties that are not available within this request interface. Optional.

IAnalyzeDefinitionParams Properties { get; }
Gets the properties describing the values within the defined request (Query, Closure, ExtendedParams).

IAnalyzeResponse GetData(ISession session, Action<IAnalyzeResponse, IAnalyzeDefinitionParams, ISession> cb, CancellationToken cancellationToken = default)
Retrieve the data from the backend service.

Task<IAnalyzeResponse> GetDataAsync(CancellationToken cancellationToken = default)
Task<IAnalyzeResponse> GetDataAsync(ISession session, CancellationToken cancellationToken = default)
Task<IAnalyzeResponse> GetDataAsync(Action<IAnalyzeResponse, IAnalyzeDefinitionParams, ISession> cb, CancellationToken cancellationToken = default)
Task<IAnalyzeResponse> GetDataAsync(ISession session, Action<IAnalyzeResponse, IAnalyzeDefinitionParams, ISession> cb, CancellationToken cancellationToken = default)
Asynchronously retrieve the data from the backend service.

Returned value

IAnalyzeDefinition object.

When requesting data using the GetData/GetDataAsync methods, we receive an IAnalyzeResponse object (implements IResponse). Unlike the other News responses, the response object's "Data" property is a plain JObject representing the computed tree expression - there is no nested data interface.

Usage

    // Analyze the following news query string
    string query = "AA";   // All Alerts
    
    //query = "PresetTopic:[Energy Market] AND 'carbon'";
    var response = Analyze.Definition(query).GetData();

    var tree = response.Data; // JObject representing the boolean filtering tree
