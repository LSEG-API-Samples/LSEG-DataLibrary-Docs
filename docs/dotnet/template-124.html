Delivery.OMMStream object

Creates a definition that can be used to get an IOMMItemStream (see below) that can be used to subscribe to streaming items of any Domain Model (e.g. MarkePrice, MarketByPrice...) exposed by the underlying WebSocket protocol of the Delivery Platform (formerly Refinitiv Data Platform).

The extended params specification provides this capability. To extend, applications must form the request properties as defined within the WebSocket Request specifications. If extended properties are included, they will be merged with all other properties specified.

GetStream()

Retrieve an IOMMItemStream to manage real-time updates for the specified items. When a session is not explicitly supplied, the default session is used.

IOMMItemStream members

GetStream() / GetStream(session) return an IOMMItemStream, used to manage the life cycle of the subscription and register callbacks.

Close(params string[] items)
Close(IEnumerable<string> items)

Close the specified items. Default: all open streams will be closed.

Streaming(bool streaming)
A value of true instructs the stream to deliver the initial image followed by updates as market conditions change. A value of false instructs the stream to deliver only the initial image, or snapshot. Optional. Default: true.

OnRefresh(Action<string, JObject, IOMMItemStream> cb)
Optional callback invoked upon receiving a Refresh message containing the fields.

OnUpdate(Action<string, JObject, IOMMItemStream> cb)
Optional callback invoked upon receiving an Update message containing the fields.

OnStatus(Action<string, JObject, IOMMItemStream> statusCb)
Optional callback invoked when a status event occurs for the specified item.

OnComplete(Action<IOMMItemStream> cb)
Optional callback invoked when the request to open the stream has completed (typically once the complete item image and/or item status messages have been received for all requested items).

OnError(Action<string, JObject, IOMMItemStream> errorCb)
Optional callback invoked if an error occurs resulting from the request.

Definition (property, IOMMStreamDefinitionParams)
Retrieve the parameters defined for the streaming request.

IOMMItemStream also implements the shared IStream interface, common to every streaming interface in the library (IOMMItemStream, IRDPItemStream, and the content-layer streams), contributing:

Open(CancellationToken cancellationToken = default)
Open the stream synchronously. Request the data from the platform and wait until all initial responses have arrived. Returns a Stream.State value (see State).

OpenAsync(CancellationToken cancellationToken = default)
Open the stream asynchronously.

Close()
CloseAsync()
Close all opened resources for the stream (equivalent to Close()/CloseAsync() with no items - see above for closing specific items).

OpenState (property, Stream.State)
Indicates if the stream is open with active streaming items.

Session (property, ISession)
Session used to open the stream.

Usage

The following example demonstrates how to create an OMM stream definition and capture snapshot data:

// Request a snapshot for the Canadian Dollar.
var stream = OMMStream.Definition("CAD=")
                      .Fields("BID", "ASK", "HIGH_1", "LOW_1")
                      .GetStream().OnRefresh((a, b, c) => {})
                      .OnStatus((a, b, c) => {});

// By setting streaming the false, we are requesting only a snapshot of the historical data 
// without any incoming streaming updates 
stream.Streaming(false).Open();

The following example demonstrates how to create an OMM stream with multiple registered callbacks and request stream data: 

var stream1 = OMMStream.Definition("EUR=")
                        .GetStream()
                        .OnRefresh((item, msg, s) => Console.WriteLine($"{DateTime.Now}:{msg}"))
                        .OnUpdate((item, msg, s) => DumpMsg(item, msg))
                        .OnStatus((item, msg, s) => Console.WriteLine($"{DateTime.Now} => Status1: {msg}"))
                        .OnError((item, msg, s) => Console.WriteLine($"Stream1 error: {DateTime.Now}:{msg}"));

The following example demonstrates how to request bulk snapshot data using the OMM Stream: 

// Read in the batch of items to request for
var items =  new List<string> { ".A1UTI", ".A3DOW", ".A4DOW", ".AAPIDX" };

var stream = OMMStream.Definition(items)
                      .GetStream()
                      .OnComplete(s => Console.WriteLine("Bulk request completed"));
 
stream.Streaming(false).Open();
