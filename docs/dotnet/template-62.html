About the Financial Contracts Option FX

Financial Contracts provide 2 main definition for retrieving options data:

OptionFxDefinition
OptionEtiDefinition


Alternatively, option data can also be retrieved using **FinancialContractsDefinition** with a specific request object.

OptionFxDefinition - options methods

InstrumentTag(string tag)
A user-defined string to identify the instrument.

FxCrossCode(string code)
The currency pair. Should contain the two currencies, ex EURUSD.

PricingParams(OptionFx.IFxPricingDefinition pricing)
Properties used to control the Fx pricing calculations.

Fields(params string[] fields)
The collection of fields included within the response. Default: all available on the server.

Fields(IEnumerable fields)
The collection of fields included within the response. Default: all available on the server.

Outputs(params FinancialContracts.Output[] outputs)
Defines the sections that will be returned within the response.

Outputs(IEnumerable<FinancialContracts.Output> outputs)
Defines the sections that will be returned within the response.

Strike(double strike)
Option strike price. Required only if pricing an OTC Option.

BuySell(FinancialContracts.BuySell buySell)
The side of the deal. Optional. Default: Buy.

CallPut(FinancialContracts.CallPut callPut)

ExcerciseStyle(OptionFx.ExerciseStyle style)

Closure(object closure)
Optionally, include a user-defined Closure to match specific requests and responses.

ExtendedParams(JObject extendedParams)
Apply any properties that are not available within this request interface. The extended params acts as a fallback measure in case properties are unavailable. It is also an alternative for users that prefer to define the request using native json definitions.

IOptionFxDefinitionParams Properties { get; }
Gets the properties describing the values within the defined request (Fields, Outputs, InstrumentTag, FxCrossCode, PricingDefinition, Strike, BuySell, CallPut, ExerciseStyle, EndDate, and more).

Returned value

IOptionFxDefinition object.

When requesting data using the GetData/GetDataAsync methods, we receive an IDataSetResponse object (implements IResponse). The response object contains a "Data" property of IDataSet type (Raw, Table, Records, Errors, IsEmpty - see FinancialContracts.Definition).

Sub-definition builders

The following static builders create the sub-definition objects accepted by PricingParams(), AsianDefinition(), BarrierDefinition(), DoubleBarriersDefinition(), BinaryDefinition(), DoubleBinaryDefinition(), ForwardStartDefinition() and FxDualCurrencyDefinition() above. Each exposes its own Properties companion interface (...Params) describing the values within the defined sub-request.

OptionFx.PricingDefinition() returns an IFxPricingDefinition (properties: IFxPricingDefinitionParams)
ValuationDate, MarketDataDate, ReportCcy, MarketValueInDealCcy, PricingModelType, PriceSide, VolatilityModel, FxSwapCalculationMethod, FxSpotObject, AtmVolatilityObject, RiskReversal10DObject, RiskReversal25DObject, Butterfly10DObject, Butterfly25DObject, ForwardPointsObject, ForeignDepositRatePercentObject, DomesticDepositRatePercentObject, ImpliedVolatilityObject, CutoffTimeZone, CutoffTime. FxSwapCalculationMethod is an OptionFx.SwapCalculationMethod value: FxSwap, FxSwapImpliedFromDeposit, DepositCcy1ImpliedFromFxSwap, DepositCcy2ImpliedFromFxSwap.

OptionFx.BidAskMidDefinition() returns an IBidAskMid (properties: IBidAskMidParams)
Bid, Ask, Mid. Used to supply the *Object parameters of PricingDefinition() above (e.g. FxSpotObject, AtmVolatilityObject).

OptionFx.AsianDefinition → IFxAsianDefinition (properties: IFxAsianDefinitionParams)
AverageSoFar, AverageType, FixingFrequency, FixingRicSource, FixingStartDate, FixingEndDate, IncludeHolidays, IncludeWeekends.

OptionFx.BarrierDefinition(double level) → IFxBarrierDefinition (properties: IFxBarrierDefinitionParams)
BarrierMode, UpOrDown, InOrOut, WindowStartDate, WindowEndDate, RebateAmount.

OptionFx.DoubleBarrierDefinition → IFxDoubleBarrierDefinition (properties: IFxDoubleBarrierDefinitionParams)
No direct setters; properties expose BarrierMode and the upper/lower Option.IDoubleBarrierInfoDefinition (BarrierUp/BarrierDown).

OptionFx.BinaryDefinition → IFxBinaryDefinition (properties: IFxBinaryDefinitionParams)
PayoutAmount, PayoutCcy. Properties also expose BinaryType, Trigger and SettlementType.

OptionFx.DoubleBinaryDefinition → IFxDoubleBinaryDefinition (properties: IFxDoubleBinaryDefinitionParams)
SettlementType, PayoutAmount, PayoutCcy. Properties also expose BinaryType, TriggerUp and TriggerDown.

OptionFx.ForwardStartDefinition → IFxForwardStartDefinition (properties: IFxForwardStartDefinitionParams)
ForwardStartDate. Properties also expose ForwardStartTenor and StrikePercent.

IFxDualCurrencyDefinition (properties: IFxDualCurrencyDefinitionParams)
Provides the details on the dual currency deposit terms (can be combined with the vanilla option definition, FxBarrierDefinition or FxDoubleBarrierDefinition). No direct setters; properties expose DepositStartDate and MarginPercent.

Usage

  1. An example of an OptionFx pricing definition with multiple properties specified
    var pricing = OptionFx.PricingDefinition().CutoffTimeZone(OptionFx.CutoffTimeZone.GMT)
                                       .FxSpotObject(OptionFx.BidAskMidDefinition().Mid(2.5))
                                       .CutoffTime("1500PM")
                                       .PricingModelType(OptionFx.PricingModelType.VannaVolga);

  2. An example of an OptionFx binary definition with multiple properties specified
var binaryDefinition = OptionFx
    .BinaryDefinition(OptionFx.BinaryType.OneTouchDeferred, 1.2001)
    .PayoutAmount(1000000);

  1. An example of an OptionFx definition with multiple properties specified
    var data = OptionFx.Definition().Fields("FxCrossCode", "EndDate", "ForeignCcy", "FxSwap", "ErrorMessage")
                             .FxCrossCode("EURUSD")
                             .SettlementType(OptionFx.SettlementType.Cash)
                             .Tenor("1M")
                             .BinaryDefinition(binary)
                             .PricingParams(pricing)
                             .GetData();

  1. An example of requesting an OptionFx data using the Financial Contracts definition with a specific request object ```csharp // FX Option (include some pricing and binary properties) var fx = new JObject() { ["fields"] = new JArray("FxCrossCode", "EndDate", "ForeignCcy", "FxSwap", "ErrorMessage"), ["universe"] = new JArray(new JObject() {

     },
     ["settlementType"] = "Cash",

 ["fxSpotObject"] = new JObject() { ["mid"] = 2.5 },

    } };

var data = FinancialContracts.Definition(fx).GetData();

```
