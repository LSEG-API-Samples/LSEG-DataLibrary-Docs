About Financial Contracts

Financial Contracts allows you to retrieve data about financial instruments using multiple content objects belonging to the Financial Contracts group that includes:

  • Bond
  • CapFloor
  • FxCross
  • Option
  • Swaption

Each asset type (Bond, OptionEti, OptionFx, etc.) implements the common IFinancialAssetType interface, exposing a single JToken Serialize() method used internally to package the asset's parameters into the JSON structure expected by the Financial Contracts endpoint.

Similarly, the pricing-parameter sub-definitions used by each asset type (e.g. Bond.PricingDefinition()) implement the common IPricingParameters interface, also exposing a JToken Serialize() method.
