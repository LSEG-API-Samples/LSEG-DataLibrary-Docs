SingleEvent.Definition object

Returned value

ISingleEventDefinition object.

When requesting data using the GetData/GetDataAsync methods, we receive an IDataSetResponse object (implements IResponse). The response object contains a "Data" property of IDataSet type.

IDataSet - properties

JToken Raw { get; }
DataTable Table { get; }
IList<IDataSetRecord> Records { get; }
JToken Errors { get; }
bool IsEmpty { get; }

Each entry in Records is an IDataSetRecord describing the requested Universe, the Fields returned, and the corresponding Data points for that instrument.

Usage

The following example demonstrates how to create a single-event definition object for VOD.L, filtering trade events within a date range.

using LSEG.Data.Content.HistoricalPricing;

var response = SingleEvent.Definition("VOD.L")
                          .EventTypes(Events.EventType.trade)
                          .Start(new DateTime(2022, 1, 1, 0, 0, 0, DateTimeKind.Utc))
                          .End("2022-01-10")
                          .GetData();
