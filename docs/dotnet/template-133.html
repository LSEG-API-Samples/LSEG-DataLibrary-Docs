About MetadataCache

MetadataCache loads and caches metadata (shared dictionaries, global metadata, and per-instrument metadata) so subsequent stream opens skip the metadata HTTP round-trip.

Non-instrument ("singleton") metadata types are accessed through their dedicated accessor (FidDictionary, EnumDictionary, ConsolidatedFields, GlobalMetadata), each an ISingletonMetadataCache. Per-instrument metadata is accessed through the InstrumentMetadata accessor, an IInstrumentMetadataCache.

Syntax

MetadataCache.FidDictionary
MetadataCache.EnumDictionary
MetadataCache.ConsolidatedFields
MetadataCache.GlobalMetadata
MetadataCache.InstrumentMetadata

MetadataCache Methods

IMetadataCacheLoaderResponse Load(ISession session = null, CancellationToken cancellationToken = default)
Task<IMetadataCacheLoaderResponse> LoadAsync(ISession session = null, CancellationToken cancellationToken = default)
Loads all singleton metadata types (FidDictionary, EnumDictionary, ConsolidatedFields, GlobalMetadata) into the cache in one call. InstrumentMetadata is excluded - it has no ambient universe and must be loaded explicitly (see below).

void Clear()
Removes all cached metadata (singleton and instrument).

ISingletonMetadataCache Methods

Each of FidDictionary, EnumDictionary, ConsolidatedFields and GlobalMetadata is an ISingletonMetadataCache:

IMetadataCacheLoaderResponse Load(ISession session = null, CancellationToken ct = default)
Task<IMetadataCacheLoaderResponse> LoadAsync(ISession session = null, CancellationToken ct = default)
Loads this metadata type into the cache.

IMetadataCacheData GetCacheSnapshot()
Reads the cached snapshot for this metadata type without triggering a load. The payload is null when the type is not cached.

void Remove()
Removes the cached entry for this metadata type.

IInstrumentMetadataCache Methods

IInstrumentMetadataCacheDefinition Definition(params string[] items)
IInstrumentMetadataCacheDefinition Definition(IEnumerable<string> items)
IInstrumentMetadataCacheDefinition Definition()
Creates a definition for the specified instrument metadata items. If created empty, populate the universe using Universe() on the returned definition, otherwise no items will be loaded.

IMetadataCacheData GetCacheSnapshot(string item)
Gets the cached instrument metadata for the specified item, without triggering a load.

IReadOnlyList<string> GetCacheUniverse()
Gets a list of all cached instrument metadata items.

void Remove(string item)
Removes the cached instrument metadata for the specified item. Use this prior to reloading an instrument to ensure fresh data is fetched rather than using potentially stale cached data.

void Clear()
Clears all cached instrument metadata entries.

IInstrumentMetadataCacheDefinition Methods

IInstrumentMetadataCacheDefinition Universe(params string[] universe)
IInstrumentMetadataCacheDefinition Universe(IEnumerable<string> universe)
Sets the universe of instruments (e.g. RIC item names) whose metadata will be loaded. Replaces any universe set previously (a set, not an append).

IInstrumentMetadataCacheDefinition InstrumentMetadataTypes(params InstrumentMetadataTypes[] instrumentMetaTypes)
IInstrumentMetadataCacheDefinition InstrumentMetadataTypes(IEnumerable<InstrumentMetadataTypes> instrumentMetaTypes)
Overrides the default set of instrument metadata types to load for the specified universe (default: all types). Values: MarketRulesData, Qualifiers, RuleReferenceData, TimeZone, TradingSessions.

IMetadataCacheLoaderResponse Load(ISession session = null, CancellationToken cancellationToken = default)
Task<IMetadataCacheLoaderResponse> LoadAsync(ISession session = null, CancellationToken cancellationToken = default)
Loads all the registered metadata into the cache.

IInstrumentMetadataCacheDefinitionParams Properties { get; }
The current request parameters, including the configured universe (Universe, InstrumentMetadataTypes).

Returned value

IMetadataCacheLoaderResponse - the aggregate result of a metadata prefetch operation:

bool IsSuccess { get; }
IReadOnlyList<IMetadataCacheLoaderError> Errors { get; }

Each entry in Errors is an IMetadataCacheLoaderError (one per singleton type, or per instrument RIC, that failed):

MetadataType MetadataType { get; }
string Item { get; }
string Error { get; }

GetCacheSnapshot() methods return an IMetadataCacheData:

MetadataType MetadataType { get; }
string Item { get; }
JObject Data { get; }

MetadataType values: FidDictionary, EnumDictionary, ConsolidatedFields, GlobalMetadata, InstrumentMetadata.

Usage

The following example demonstrates loading, reading and removing both singleton and per-instrument metadata.

using LSEG.Data.Core;
using LSEG.Data.Metadata.Cache;
using LSEG.Data.Metadata.Interfaces;

ISession session = Sessions.GetSession();
session.Open();

// Load ALL singleton metadata types (FID dictionary, enum dictionary, consolidated fields, global metadata) in one call.
var result = MetadataCache.Load();

// Or load individual singleton types on demand.
MetadataCache.GlobalMetadata.Load();
MetadataCache.FidDictionary.Load();
MetadataCache.EnumDictionary.Load();

// Load instrument metadata for a universe. A bad RIC does not abort the others.
var instrumentResult = MetadataCache.InstrumentMetadata
    .Definition("AAPL.O", "NVDA.O", "invalid")
    .Load();

// A new universe replaces the previous one (it does not append).
var instrumentResult2 = MetadataCache.InstrumentMetadata
    .Definition()
    .Universe("GOOGL.O")
    .Load();

// GetCacheSnapshot(...) NEVER hits the network - it returns what is cached.
// Data is null when the item was never loaded (or failed).
var globalSnapshot = MetadataCache.GlobalMetadata.GetCacheSnapshot();
var aaplSnapshot = MetadataCache.InstrumentMetadata.GetCacheSnapshot("AAPL.O");

// Removal is a pure cache operation.
MetadataCache.InstrumentMetadata.Remove("NVDA.O");
MetadataCache.FidDictionary.Remove();

// Clear ALL instrument metadata at once.
MetadataCache.InstrumentMetadata.Clear();

// Clear everything.
MetadataCache.Clear();

session.Close();
