PlatformSession

The PlatformSession connects directly to the platform (LSEG Data Platform / RDP) or through a local real-time enterprise platform. The PlatformSession specification details the properties specific to RDP, including how an RDP user is authenticated when accessing content from the platform. A session into RDP supports requests such as streaming data, non-streaming data, message queues, and bulk data.

Connecting directly to RDP requires a platform account (a user or a machine account) and platform credentials. Working through a local platform requires the IP of the local platform and a user name (e.g. a DACS user name).

For desktop connections, see DesktopSession and DesktopDirectSession.

The types on this page live in the LSEG.Data.Core namespace.

Entry points

The PlatformSession class exposes a Definition(...) factory that returns an IPlatformSessionDefinition fluent builder; the builder's GetSession() method finalises the request and returns an ISession.

PlatformSession.Definition(string sessionName = default)
PlatformSession.Definition(Stream stream, string resourceName = default)
PlatformSession.Definition(JObject config)
PlatformSession.Definition(string sessionName, Stream stream, string resourceName = default)
PlatformSession.Definition(string sessionName, JObject config)
Define a Platform Session request. When sessionName is omitted, the sessions.platform.default entry from the configuration is used.

IPlatformSession members

IPlatformSession is the platform-specific session interface. It extends the common ISession interface (see Sessions for Open, OpenAsync, Close, OnState, OnEvent, and the state/event members) with the following:

Member Kind Description
IPlatformSession OnStreamingEndpoint(Action<string, IList<IStreamingEndpoint>, ISession> cb) method Optional callback invoked to report all the RDP platform streaming endpoints.
IPlatformSessionDefinitionParams Definition property Retrieve the parameters defined for the Platform Session.

Authentication — OAuth 2.0 grant types

PlatformSession authenticates against RDP with an IGrant implementation supplied to the session definition via OAuthGrantType(IGrant grant). Three grant classes are available; all implement IGrant, are IDisposable, and are typically created inside a using scope.

GrantPassword — Resource-Owner Password Grant. Exchanges a user's credentials for an access token.

Member Kind Description
GrantPassword UserName(string user) method Defines the user's username required by the grant type. Required.
GrantPassword Password(string password) method Defines the user's password required by this grant type. Required.
GrantPassword Scope(string scope) method Limits the scope of RDP services for this sign-on session. Optional. Default: trapi (full scope of services).

ClientCredentials — Client Credentials Grant. Exchanges a client ID / client secret pair for an access token.

Member Kind Description
ClientCredentials ClientID(string id) method Defines the client ID required by the grant type. Required.
ClientCredentials ClientSecret(string secret) method Defines the client secret required by this grant type. Required.
ClientCredentials Scope(string scope) method Limits the scope of RDP services for this sign-on session. Optional. Default: trapi.

ClientAssertion — Client Credentials Grant with a signed JWT assertion.

Member Kind Description
ClientAssertion ClientID(string id) method Defines the client ID required by the grant type. Required.
ClientAssertion JWKFilename(string fname) method Defines the JWK file used to generate the assertion.
ClientAssertion JsonWebKey(JObject jwk) method Defines the JWK used to generate the assertion.
ClientAssertion Scope(string scope) method Limits the scope of RDP services for this sign-on session. Optional. Default: trapi.

Example

Create a Platform session with a password grant:

using LSEG.Data.Core;

using var grantPassword = new GrantPassword().UserName("<machine-id>")
                                             .Password("<password>");

using (var platformSession = PlatformSession.Definition()
                                            .AppKey("<your-app-key>")
                                            .OAuthGrantType(grantPassword)
                                            .TakeSignonControl(true)
                                            .GetSession())
{
    platformSession.OnStreamingEndpoint((api, endpoints, s) => { /* inspect endpoints */ })
                   .OnState((state, msg, s) => Console.WriteLine($"State: {state}. {msg}"))
                   .OnEvent((eventCode, msg, s) => Console.WriteLine($"Event: {eventCode}. {msg}"));

    platformSession.Open();
}
