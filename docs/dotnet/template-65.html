Option.OptionSelection

OptionSelection for the financial instruments defines how the timestamp of the option is selected:

Name Value
OptionSelection.Open 'Open'
OptionSelection.Close 'Close'
OptionSelection.Default 'Default'

This enumeration applies to both **LSEG.Data.Content.IPA.OptionFx** and **LSEG.Data.Content.IPA.OptionEti**.
