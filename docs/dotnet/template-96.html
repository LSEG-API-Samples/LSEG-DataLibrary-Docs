Pricing.Definition object

The Pricing Definition defines a request used to retrieve pricing data for specified instruments.

Syntax

Pricing.Definition() Pricing.Definition(params string[] universe) Pricing.Definition(IEnumerable<string> universe)

At least one universe has to be specified either when creating the definition or using the Universe() method

PricingDefinition Methods

IPricingDefinition Universe(params string[] universe)
IPricingDefinition Universe(IEnumerable<string> universe)
List of RICs to request. Required.

IPricingDefinition Service(string service)
The name of the service providing the desired streaming price data. Optional. Default: defined within the streaming platform.

IPricingDefinition Fields(params string[] fields)
IPricingDefinition Fields(IEnumerable<string> fields)
Specify the specific fields delivered when messages arrive. Optional. Default: all fields.

IPricingDefinition ExtendedParams(JObject extendedParams)
Define additional request properties that will be merged with all other properties specified. Applications must form the request properties as defined within the WebSocket Request specifications. Optional.

IPricingDefinition Closure(object closure)
Optionally, include a user-defined Closure to match specific requests and responses.

IPricingDefinitionParams Properties { get; }
Gets the properties describing the values within the defined request (Universe, View, Service, ExtendedParams, Closure).

Retrieve a streaming interface to manage real-time updates for the specified universe of items. See Pricing.Stream.

Returned value

IPricingDefinition object.

When requesting data using the GetData/GetDataAsync methods, we receive an IPricingResponse object (implements IResponse). The response object contains a "Data" property of ISnapshotData type.

Usage

The following example demonstrates how to create a pricing definition for EUR= and USD= instruments.

using LSEG.Data.Content.Pricing;

var definition = Pricing.Definition("EUR=", "USD=")
                        .Fields("BID", "ASK"); // If no fields are specified, all available fields are returned
