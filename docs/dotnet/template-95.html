GetStream

Creates and returns the pricing stream that allows you to get streaming data for previously defined instruments.

Syntax

definition.GetStream()
definition.GetStream(ISession session)

Returned value

Pricing.Stream object

Usage

The following example demonstrates how to retrieve streaming data for EUR= and USD= instruments. 

var definition = Pricing.Definition("EUR=", "USD=").Fields("BID", "ASK");

var stream = definition.GetStream().Open();
