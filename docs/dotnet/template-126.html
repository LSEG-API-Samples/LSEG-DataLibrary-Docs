Delivery.Queue.Queue object

A class providing queueing capabilities for Research, News headlines and stories.

Syntax

Delivery.Queue.Definition()
Delivery.Queue.Definition(string endpointUrl)
Define the queue properties to manage and retrieve messages from queues defined within the cloud.
Queueing capabilities currently support Research, News headlines and stories.

Delivery.Queue.Params()
Defines a request to specify query parameters when retrieving a message queue from the cloud.
Refer to the "message-services" endpoints within the RDP Playground for the available parameters.
This method returns a ParamsDefinition.

Methods of Queue definition

Endpoint(string endpoint)
Endpoint(Uri endpoint)
A reference to a message queue resource within the cloud.
The endpoint URL refers to message queue services such as Research, News Headlines, News Stories, etc.

CreateQueueManager()
Based on the specified message queue resource, as defined by the Endpoint specification, define a queue manager that supports the ability to manage queues within the cloud.

CreateAWSSubscriber(IQueueNode queue)
For the specified queue, create a queue subscriber to pull data from that queue.

Properties (property, IQueueDefinitionParams)
Retrieve the parameters defined within the request.

IQueueManager members

CreateQueueManager() returns an IQueueManager, responsible for creating, retrieving and deleting queues in the cloud.

CreateQueue(JObject criteria = default, Queue.CloudType cloudType = Queue.CloudType.AWS, CancellationToken cancellationToken = default)
CreateQueueAsync(...)
Create a new queue in the cloud, optionally including additional criteria. Returns the created IQueueNode, or null if an error occurs.

GetQueue(string subscriptionID, CancellationToken cancellationToken = default)
GetQueue(Queue.IParamsDefinition definition, CancellationToken cancellationToken = default)
GetQueueAsync(...)
Retrieve an existing queue based on the subscription ID, optionally with additional criteria. Returns the IQueueNode, or null if an error occurs.

GetAllQueues(CancellationToken cancellationToken = default)
GetAllQueuesAsync(...)
Retrieve all active queues. Returns the list of active queues, or null if an error occurs.

DeleteQueue(IQueueNode queue, CancellationToken cancellationToken = default)
DeleteQueue(string subscriptionID, CancellationToken cancellationToken = default)
DeleteQueueAsync(...)
Delete an active queue based on the queue node or its subscription ID. Returns true if successfully deleted, false if the queue doesn't exist.

DeleteAllQueues(CancellationToken cancellationToken = default)
DeleteAllQueuesAsync(...)
Delete all active queues. Returns true if successfully deleted, false if there were no active queues.

OnError(Action<JObject, IQueueManager> cb)
Callback invoked when an error occurs for any action performed on the queue manager.

Session(ISession session)
Define a session associated with all actions on the queue manager. Required.

Properties (property, IQueueManagerParams)
Property details for the manager, including the associated Session and Definition.

IQueueSubscriber members

CreateAWSSubscriber(...) returns an IQueueSubscriber (extends ISubscriber), responsible for pulling messages off a queue.

StartPolling(Action<IQueueResponse, IQueueSubscriber> cb)
StartPollingAsync(Action<IQueueResponse, IQueueSubscriber> cb)
StartPollingAsync(Func<IQueueResponse, IQueueSubscriber, Task> cb)
Start polling the queue for messages and dispatch to the supplied callback. Starts a long-running background task that only completes when StopPolling()/StopPollingAsync() is called. Returns whether polling was successfully started.

GetNextMessage(int timeoutInSeconds = 20, CancellationToken cancellationToken = default)
GetNextMessage(int timeoutInSeconds, Action<IQueueResponse, IQueueSubscriber> cb, CancellationToken cancellationToken = default)
GetNextMessageAsync(...)
Retrieve the next message from the queue, waiting up to timeoutInSeconds (default: 20). Returns the response, or null if cancelled.

StopPolling()
StopPollingAsync()
Stop polling the queue for messages. Any messages already in the processing loop will be delivered.

Usage

The following example demonstrates how to use a Queue Definition:

const string newsStoriesEndpoint = "https://api.refinitiv.com/message-services/v1/news-stories/subscriptions";

ISession session = Sessions.GetSession();

if (session.Open() == Session.State.Opened)
{
    var definition = Queue.Definition(newsStoriesEndpoint);

    // Create a QueueManager to actively manage our queues
    var manager = definition.CreateQueueManager()
                            .OnError((err, qm) => Console.WriteLine(err));

    // First, check to see if we have any news headline queues active in the cloud...
    List<IQueueNode> queues = manager.GetAllQueues();

    // Determine if we retrieved anything...create on if not.  
    IQueueNode queue = (queues.Count > 0 ? queues[0] : manager.CreateQueue());

    // Ensure our queue is created
    if (queue != null)
    {
        // Start pulling off news headline messages from the queue - we need to define a subscriber
        var subscriber = definition.CreateAWSSubscriber(queue);

        try
        {
            // Open the subscriber to begin polling for messages. Use Async() as this method is a long running task.
            var task = subscriber.StartPollingAsync((story, s) => DisplayStory(story));

            // Let the program run for a few seconds before proceeding via key press 
            Console.ReadKey();

            // Close the subscription - stops polling for messages
            subscriber.StopPolling();
            task.GetAwaiter().GetResult();
            Console.Write("\nStopped polling for messages from the queue. <Enter> to exit...");
        }
        catch (Exception e)
        {
            Console.WriteLine(e);
        }

        Console.ReadLine();
    }
}
