ESG.Scores object

Scores provides full coverage of LSEG's proprietary ESG Scores with full available history.

Syntax

Scores.Definition(params string[] universe)
Scores.Definition(IEnumerable<string> universe)
Scores.Definition()

ScoresDefinition Methods

IScoresDefinition ServiceType(ServiceType type)
The service type providing different coverage. Optional. Default: ServiceType.full.

IScoresDefinition Universe(params string[] universe)
IScoresDefinition Universe(IEnumerable<string> universe)
A comma-separated list of items. Required.

IScoresDefinition Start(int start)
IScoresDefinition End(int end)
Range representing the number of Financial Years of data to return. The options available start with 0 for the latest Financial and then negative numbers for further Financials - for example, Start(0) and End(-2) will return the last three Financial years. Optional. Default: -20.

IScoresDefinition Closure(object closure)
Optionally, include a user-defined Closure to match specific requests and responses.

IScoresDefinition ExtendedParams(JObject extendedParams)
Apply any properties that are not available within this request interface. Optional.

IScoresDefinitionParams Properties { get; }
Gets the properties describing the values within the defined request (ServiceType, Universe, Start, End, Closure, ExtendedParams).

Returned value

IScoresDefinition object.

When requesting data using the GetData/GetDataAsync methods, we receive an IDataSetResponse object (implements IResponse). The response object contains a "Data" property of IDataSet type.
